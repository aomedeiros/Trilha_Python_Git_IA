# Trilha Python Git IA

Projeto de estudos de Python, Git e Inteligência Artificial.

## Objetivo

Organizar os exercícios, códigos, testes e materiais desenvolvidos ao longo da pós-graduação em Engenharia de Dados e Inteligência Artificial.

## Tecnologias e ferramentas

- Python
- Git e GitHub
- Poetry
- Pytest
- Ruff
- MkDocs

## Estrutura do projeto

- `src/`: código-fonte Python.
- `tests/`: testes automatizados.
- `docs/`: documentação.
- `scripts/`: scripts auxiliares.
- `pyproject.toml`: configuração do projeto e dependências.
- `poetry.lock`: registro das versões das dependências.
- `mkdocs.yml`: configuração da documentação.

Projeto de estudos em desenvolvimento.
